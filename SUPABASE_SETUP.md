# Подключение Supabase для SamHelp

## Что синхронизируется

В облако отправляются **только общие таблицы и приложения** из раздела «Общее».

Остаются локальными на каждом компьютере:
- контакты и история/напоминания, связанные с ними;
- личные ссылки на таблицы;
- личные ссылки на приложения;
- локальные настройки интерфейса и фильтры.

Так личные записи не попадут в общий список и не будут видны другим сотрудникам.

## Архитектура

- Интерфейс остаётся на HTML, CSS и JavaScript.
- Electron остаётся оболочкой Windows-приложения.
- Supabase Auth будет отвечать за вход пользователей.
- PostgreSQL хранит общие ссылки в `public.shared_links`.
- `public.shared_editors` содержит UUID пользователей, которым разрешено изменять общий раздел.
- Row Level Security (RLS) проверяет права на стороне базы, а не только скрывает кнопки в интерфейсе.

## Подготовка проекта Supabase

1. Создайте проект Supabase.
2. Откройте SQL Editor и выполните миграцию:
   `supabase/migrations/202611120001_shared_data.sql`.
3. В Authentication настройте способ входа для сотрудников. Для первого этапа предпочтительны приглашения/создание пользователей администратором, а не открытая регистрация.
4. После создания пользователей добавьте выбранных редакторов SQL-командой из конца миграции. Используйте их реальные email.
5. Скопируйте Project URL и publishable/anon key из настроек API проекта.

## Важные правила безопасности

- В Electron-приложение можно помещать только publishable/anon key. Это публичный клиентский ключ, его безопасность обеспечивается RLS.
- Никогда не помещайте в HTML, JavaScript, репозиторий или сборку ключ `service_role` / secret key.
- Не храните пароли сотрудников в `localStorage`. При переходе на Supabase Auth старую самодельную авторизацию нужно отключить и мигрировать на сессии Supabase.
- До подключения Supabase к приложению текущая локальная авторизация и локальное хранение продолжают работать. Миграция базы сама по себе ещё не включает синхронизацию.

## Следующий этап

После создания Supabase-проекта понадобятся Project URL и publishable/anon key. Тогда можно подключить клиент Supabase, перенести только записи без `owner` из `state.links.sheets/apps` в `shared_links`, а личные записи оставить в localStorage. Существующие контакты не загружаются в облако.
