# Мои контакты — сборка Windows EXE

Проект упакован в Electron. GitHub Actions собирает Windows-установщик `.exe`.

## Сборка через GitHub
1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки.
3. Откройте вкладку **Actions**.
4. Выберите **Build Windows installer** → **Run workflow**.
5. После успешной сборки откройте её и скачайте артефакт `Moi-Kontakty-Windows-Installer`.
6. Внутри будет `Moi-Kontakty-Setup-1.0.0.exe`.

## Локальная сборка
Нужен Node.js 22 или новее:
```bash
npm install
npm run dist
```
Готовый установщик появится в `release`.

## Иконка
Пользовательская иконка ещё не добавлена. Когда пришлёте её, подготовим Windows-файл `.ico` и пропишем его в `package.json`.

## Хранение данных
Контакты и учётные записи хранятся локально на компьютере в профиле приложения. Автоматической синхронизации между компьютерами пока нет. Для переноса данных используйте «Сохранить копию» и «Загрузить копию».

## Безопасность
Включены `contextIsolation`, `sandbox`, отключён `nodeIntegration`. Не добавляйте секреты и токены в репозиторий.
